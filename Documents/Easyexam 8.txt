Below is a **JSON schema + sample data** that turns the **Year 3 Maths** and **Year 3 English** 10-week sequences into a curriculum configuration you can load directly into your app.

It’s designed to:

- Be **state-agnostic** at the top level (same structure for VIC and NSW).  
- Store **canonical skill definitions** once, with state-specific mappings.  
- Support your **weekly new skill selector** and your **spaced-repetition engine**.  
- Allow easy extension to other year levels and subjects.

***

## 1. High-level structure

Top-level keys:

```json
{
  "version": "1.0",
  "subjects": {
    "maths": { ... },
    "english": { ... }
  },
  "states": ["VIC", "NSW"],
  "year_levels": [3],
  "weeks_per_term": 10
}
```

Each subject contains:

- `skills`: array of canonical skill definitions.  
- `sequences`: mapping of `year_level` → `term` → `week` → list of skill IDs to mark as “new”.

***

## 2. Skill definition schema

Each skill:

```json
{
  "id": "string (unique, e.g. 'M3N01_represent_numbers_10k')",
  "subject": "maths | english",
  "year_level": 3,
  "strand": "string (e.g. 'Number', 'Reading', 'Writing', 'Language')",
  "description": "string (child/teacher-friendly)",
  "ac_codes": ["AC9M3N01", "AC9M3N02"],
  "state_mappings": {
    "VIC": {
      "level": 3,
      "phrasing": "string (VIC-specific wording)",
      "local_codes": ["VCMNA103"] // optional
    },
    "NSW": {
      "stage": "Stage 2",
      "subarea": "Representing numbers",
      "outcomes": ["MA2-MRNS-01"]
    }
  },
  "metadata": {
    "difficulty_band": "core | extension",
    "typical_weeks_to_mastery": 2
  }
}
```

You can add more fields later (e.g., links to item banks, sample items, etc.).

***

## 3. Sequence schema

For each subject and year:

```json
"sequences": {
  "3": {
    "1": {
      "1": {
        "new_skill_ids": ["M3N01_represent_numbers_10k", "M3M01_metric_units_intro"],
        "focus_notes": "Week 1 – Place value and number representation to 10,000"
      },
      "2": { ... },
      ...
      "10": { ... }
    }
  }
}
```

Where:

- `"3"` = year level  
- `"1"` = term 1 (you can add more terms later)  
- `"1"`–`"10"` = week index  
- `new_skill_ids` = list of skill IDs to mark as “new” that week.  
- `focus_notes` = optional human-readable label (for admin/teacher UI).

## How to use this in your app

- Load this JSON at startup or via an admin “curriculum config” upload.  
- When a child is:
  - `state = "VIC"` or `"NSW"`,  
  - `year_level = 3`,  
  - `subject = "maths"` or `"english"`,  
  - `term = 1`, `week = N`,  
  your backend:
  - Reads `subjects[subject].sequences["3"]["1"][N].new_skill_ids`.  
  - For each skill ID, looks up `subjects[subject].skills` and uses the matching `state_mappings` entry to show state-appropriate phrasing and codes.  
- Your **daily session builder** then treats these skills as “new” for that week, while your spaced-repetition engine schedules reviews.
