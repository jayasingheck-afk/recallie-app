Below is a compact **“admin view” JSON** that maps each Year 3 Maths and English skill to human‑readable labels suitable for your dashboard UI (e.g., curriculum manager, weekly planner, teacher view).

It’s designed to be:

- Easy to scan in a UI table or dropdown.  
- State‑aware (shows VIC/NSW phrasing and codes).  
- Linked back to the canonical `skill.id` from your main curriculum config.

***

## Admin view JSON schema (conceptual)

Each entry:

```json
{
  "skill_id": "string (matches main config)",
  "subject": "maths | english",
  "year_level": 3,
  "strand": "string",
  "labels": {
    "canonical": "string (short, teacher-friendly)",
    "VIC": {
      "label": "string (VIC phrasing, shortened)",
      "codes": "string (comma-separated)"
    },
    "NSW": {
      "label": "string (NSW subarea + outcome)",
      "codes": "string (comma-separated)"
    }
  },
  "typical_weeks": ["1","2", "..."] // optional: which weeks this skill is “new” in Term 1
}
```

- Display in tables like:

  - Columns: `Subject | Strand | Canonical label | VIC label + codes | NSW label + codes | Typical weeks`
  - Filters: by `subject`, `strand`, `week`, `state`.

- When an admin or teacher views “Week N”:
  - Filter skills where `typical_weeks` includes `N`.
  - Show state-specific labels/codes depending on selected state.
